 🏦 Banking Analytics Project

 📌 Overview
This project performs end-to-end banking data analysis using Python, Pandas, and Matplotlib. It combines customer, card, and transaction datasets to uncover meaningful business insights and spending patterns.

 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Git & GitHub

 📊 Project Workflow
- Loaded and explored banking datasets.
- Performed data cleaning and preprocessing.
- Merged Users, Cards, and Transactions data.
- Analyzed yearly income and credit score distributions.
- Identified premium customers based on income and credit score.
- Analyzed card brand and card type distributions.
- Calculated average transaction amount by card brand.
- Identified top customers based on total transaction spending.
- Created visualizations using Matplotlib.

 📈 Key Insights
- Mastercard and Visa are the most commonly used card brands.
- Debit cards are more popular than credit cards.
- Premium customers can be identified using high credit scores and yearly income.
- Customer spending patterns vary significantly across card brands.
